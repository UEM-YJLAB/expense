# Word 填写与更新

## 母版与样式

首次生成使用本 Skill 的 `assets/报销内容简要说明.docx` 作为参考和复制源，`assets/母版预览.png` 提供其页面外观。使用当前 Agent 环境可用的 DOCX 工具完成创建、模板处理和渲染；环境提供 documents 技能时按需复用，并按所用工具的要求加载依赖和运行时。

保留母版作为只读参考，在任务临时目录编辑副本。更新时以现有正式说明为编辑基础，保留用户已经确认的内容和配图，并沿用当前文档的版式。

| 项目 | 母版设置 |
| --- | --- |
| 纸张 | A4 纵向，单 section、单栏 |
| 页边距 | 左右 1.25 英寸，上下 1 英寸 |
| 正文 | Songti SC，12 磅，1.5 倍行距 |
| 首行缩进 | 类别及用途等段落沿用母版的 2 字缩进 |
| 标题 | Title 样式，Songti SC，22 磅加粗，居中 |
| 结构 | 项目资料、报销明细及用途、价格总计、按需的特殊采购说明 |

尽量复用源段落、run 属性、真实样式和编号，以相同模式增删条目。特殊采购栏目通过母版的编号设置显示“二、”，复制时保留该编号关系。

## 插槽与内容

| 占位字段 | 使用方式 |
| --- | --- |
| `{{项目编号}}` | 填入用户提供的项目编号 |
| `{{项目名称}}` | 填入用户提供的项目名称 |
| `{{费用类别}}` | 按实际发票组织费用类别；可复制类别段落增补 |
| `{{物品或服务名称}}`、`{{具体用途}}` | 填入已经确认的分类用途 |
| `{{同类物品名称}}`、`{{合并用途}}` | 用于同类物品合并表述，按实际条目增删 |
| `{{价格总计}}` | 按发票号码去重后汇总本次有效发票的价税合计，保留两位小数 |
| `{{特殊采购项目}}`、`{{用户提供的原因说明}}` | 根据用户原文填写实物或服务的采购原因 |
| `{{可选佐证图片}}` | 替换成用户提供的对应图片，或在无配图时删除该占位段 |

正式文档按项目合并成一份。正文省略按人分组、人员明细和个人小计，姓名用于工作区命名、文件命名与归属确认。全部报销明细之后、特殊采购说明之前保留一行 `价格总计：{{价格总计}} 元`，正式文档将该占位符替换为计算结果。

用途条目数量由实际内容决定，合并同类物品，保留发票中已经明确的数量和规格。采购事实和特殊采购原因以用户提供的信息为依据。服务类条目按实际服务用途填写。

本次有特殊采购时保留对应栏目和条目；本次特殊采购条目为空时删除该栏目。所有占位符在正式交付前填入实际内容或随可选段落一并删除。

## 配图

用户提供佐证图片时，嵌入对应说明下方，保持比例，控制在正文有效页面范围内。优先采用随文字排列的图片，避免浮动对象覆盖正文；长图按可读性和分页情况调整尺寸。图片内容清晰，原因段与图片保持对应。

## 更新与写入

首次生成前确认必需信息、材料和用途已经收齐并确认。更新时先重新读取当前全部发票，按相同口径重新计算价格总计，将新增用途和采购原因与原说明合并，保留已经确认的内容。

将待交付版本先保存到任务临时目录，使用可用的文档渲染工具生成预览并逐页检查。正式覆盖前，把现有 `报销内容简要说明.docx` 备份至工作区的 `历史备份（旧版本，忽略）`，采用带本地时间的文件名；同名追加序号。最后把已检查的版本写入姓名工作区根目录。

## 中文渲染

中文渲染出现缺字时，检查当前环境的中文字体和字体发现配置。使用 macOS 捆绑 LibreOffice 时，可在本次渲染进程中将 `FONTCONFIG_FILE` 指向该 LibreOffice 的 `Contents/Resources/fontconfig/fonts.conf`，并将 `SAL_FONTPATH` 设为 `/System/Library/Fonts/Supplemental`，然后重新渲染。运行时位置按当前环境定位。

逐页检查中文、字号、段落、编号、图片、分页和占位字段；检查项目资料准确、文档内容与全部有效发票对应。成功后交付正式 DOCX，渲染中间文件保留在任务临时目录。
