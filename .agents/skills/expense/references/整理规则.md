# 报销材料整理规则

这些规则来自用户已经确认的个人工作流程。使用者在本次任务中明确调整规则时，以本次指示为准。

## 工作区与姓名

工作区目录使用本次使用者姓名，一个工作区对应一个项目。多人报销仍使用一个工作区，发票及配套材料分别按所属报销人的姓名命名。用户姓名和发票人员归属分别确认。

`发票`、`订单截图`、`付款记录`、`历史备份（旧版本，忽略）` 四个目录始终保留，允许为空。读取当前材料时跳过历史备份目录，旧版材料仅作为用户明确要求时的历史参考。

用户指定已有材料时，核对真实目录和文件清单。只整理本次指定范围内的材料，其余项目资料保持原样。

## 识别发票

每张发票记录当前路径、发票号码、物品或服务名称、价税合计、人员归属，并保留订单和付款材料的关联关系。发票号码按字符串处理，完整保留前导零。

金额以当前 PDF 票面价税合计为准。文件名中已有金额可用于交叉核对。扫描件或提取结果存在疑点时查看票面，将仍需确认的事项集中向用户询问。

按实际物品或服务拟定简短、可识别的名称；一票多项时采用能涵盖实际内容的名称，必要时向用户确认。

## 文件命名

| 材料 | 文件名格式 | 金额来源 |
| --- | --- | --- |
| 发票 PDF | `物品名称-姓名-价税合计.pdf` | 单张发票票面的价税合计 |
| 订单截图 | `物品名称-姓名-实付金额.原扩展名` | 该订单材料显示的实付金额 |
| 付款记录 | `物品名称-姓名-实付金额.原扩展名` | 该付款记录显示的实付金额 |

金额保留两位小数，采用十进制处理。例如 `物品甲-张三-220.00.pdf`。

文件内容保留原样。统一命名直接用于当前工作区的文件；重名时在扩展名前追加 `-1`、`-2` 等序号，例如 `物品甲-张三-220.00-1.pdf`。已有其他文件采用继续避让的序号，保持全部文件完整。

订单截图和付款记录分别采用各自材料中的实付金额。一份订单材料可关联同一订单的多张发票，包括商品发票和运费发票，关联关系依据订单号、商品信息和用户确认结果。共享订单材料保留一份即可，其名称可以概括对应物品。

## 重复发票

按发票号码识别重复。相同票号的文件全部保留，并向用户提示重复关系；同一票号的内容在说明中纳入一次。不同票号分别处理，即使名称、金额完全相同。

同一票号出现互相矛盾的票面内容时，保留文件并请用户确认有效内容。

## 价格总计

价格总计位于全部报销明细之后、特殊采购说明之前，采用 `价格总计：金额 元` 的格式，金额保留两位小数。

按发票号码去重后，将本次项目全部有效发票的票面价税合计相加；多人发票合并为一个总计，同一票号计入一次。使用十进制金额计算，新增或调整发票时重新汇总。订单截图和付款记录用于关联核对。

## 材料阈值

判定单位为单张发票的价税合计。

| 单张发票的价税合计 | 必需基础材料 |
| --- | --- |
| 低于 200.00 元 | 发票 PDF |
| 达到或超过 200.00 元 | 发票 PDF、对应订单截图、对应付款记录 |

200.00 元计入需要订单截图和付款记录的范围。低于 200.00 元时，这两类材料由用户自愿提供；目录继续保留。用户已经提供的配套材料照常整理和关联。

对每张达到阈值的发票确认订单和付款材料的对应关系；共享订单材料可同时覆盖该订单下已确认关联的多张发票。

## 特殊采购

实物特殊采购的“无京东自营”说明由用户针对相关物品自行提供；低于 200.00 元的相关采购同样适用。先确认相关采购范围、渠道和用户原文，再整理措辞与排版。

特殊采购事实和原因均以用户答复为依据。保留原文中的限定条件，使用用户提供的品牌、规格和渠道信息。

特殊采购佐证图片为可选材料。用户提供或指定图片时，将其嵌入对应说明；无配图时保留已确认的原因文字即可。图片的可选性质单独判断，达到阈值的订单截图和付款记录仍按上一节要求提供。

打印、信息服务等服务类发票按实际服务内容说明项目用途。涉及特殊采购时向用户询问实际原因，按服务事实填写。

## 待补材料与用途确认

先完成信息明确的发票识别和重命名，再集中列出待补清单。清单通过当前文件名或票号定位，逐项说明需要的人员归属、截图、付款记录、采购原因或事实确认。

用途由项目资料和发票内容拟稿，同类物品合并，集中请用户确认。可把用途拟稿和材料清单在同一轮交给用户，已确认事项直接复用。

正式说明的写入条件为：项目信息与姓名明确，票面和归属明确，必需材料及原因说明收齐，用途已经确认。条件满足后继续生成。

## 增量和历史版本

更新时重新读取当前全部发票，继续复用已确认的用途和采购原因，新增内容按相同规则补充。

所有明确属于旧版本的文档和材料统一放入 `历史备份（旧版本，忽略）`。更新前备份现有说明，名称为 `报销内容简要说明-YYYYMMDD-HHmmss.docx`；使用本地操作时间，重名追加序号。当前有效发票的重复文件继续按重复规则保留。
