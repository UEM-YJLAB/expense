# 报销信息采集表

使用时先收集用户姓名、项目编号、项目名称、报销人姓名及每张发票的人员归属。工作区目录以用户姓名命名，发票文件按所属人员姓名命名。可在对话中逐项回答，也可填写本表；其余信息在读取发票和配套材料后集中补充。
